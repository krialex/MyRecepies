# My Recipes

A simple website with my recipies, build with HTML, SCSS, Bootstrap and JS

## Get started

### Must have

- Node.js installed
- Internet connection (for Bootstrap - CDN)

### Clone the project

1. Clone this repo:

   ```
   git clone https://github.com/ditt-brukernavn/myrecipies.git
   ```

2. Install dependencies:

   ```
   npm install
   ```

3. Build and run project:

   ```
   npm run build
   ```

   ```
   npm run watch
   ```
